# Split ZIP fixture

`WinZip26.nocomp.multi.z01` and `WinZip26.nocomp.multi.zip` are a small upstream test fixture from the SharpCompress repository:

- https://github.com/adamhathcock/sharpcompress/blob/master/tests/TestArchives/Archives/WinZip26.nocomp.multi.z01
- https://github.com/adamhathcock/sharpcompress/blob/master/tests/TestArchives/Archives/WinZip26.nocomp.multi.zip

They are used only by integration tests for split-volume extraction and are not a sample of the Phong Vân Kiếm client archive.
